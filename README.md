This project accompanies the work presented in ([Author] et al.)* 'National-Scale Assessment of Tangible Cultural Heritage Exposure to Climate-Related Coastal Hazards in Lebanon'*. It contains the following codes, all written in MATLAB (R2026a):

- processData.m
- heatMaps.m
- eslAnalysis.m
- getMWH.m
- getRunup.m
- getIndexScores.m

processData.m, heatMaps.m, and eslAnalysis.m were all used in the coastal flooding assessment conducted in section 3.2.2 of the paper. getMWH, getRunup, and getIndexScores, were used in section 3.3.
